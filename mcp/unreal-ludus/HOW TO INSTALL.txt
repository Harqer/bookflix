How to Install Ludus AI in Unreal Engine
==========================================

1. Close Unreal Engine if it's running.

2. Open this zip file and unpack it.

3. Move the LudusAI folder to the Marketplace folder at:

       ENGINE_FOLDER\Engine\Plugins\Marketplace

   By default on Windows:

       C:\Program Files\Epic Games\UE_(your engine version)\Engine\Plugins\Marketplace

   Note: If you don't have a Marketplace folder, create it.

4. Open Unreal Engine and your project.

5. Go to Edit -> Plugins, find "Ludus AI", enable it, and restart
   Unreal Engine when prompted.

6. Open Tools -> Ludus AI, log in and start creating!

For more information visit: https://app.ludusengine.com
