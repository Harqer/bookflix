# Bookflix - The Sovereign Cinematic Studio

Transform any book, PDF, or narrative prompt into a theatrical-grade feature film or episodic series. Bookflix is an autonomous, theory-driven cinematic production studio that leverages advanced AI orchestration and a sovereign GPU fleet to move from narrative intent to rendered asset with zero manual intervention.

## 🎬 Core Capabilities

- **Multi-Format Ingestion**: Process raw prompts, full-length books, or academic PDFs into structured screenplays.
- **Variable Length Production**: Generate everything from short cinematic "teasers" to feature-length episodic content.
- **Autonomous Directorial Fleet**: 
    - **Llama Scripter**: Archetype-driven narrative analysis and screenplay generation.
    - **Music Theorist**: Orchestration grounded in Rimsky-Korsakov's classical principles and the neuroscience of dissonance.
    - **Cinematographer**: Theory-aware shot composition and lighting orchestration.
- **Sovereign GPU Fleet**: High-fidelity rendering via Modal, orchestrating ComfyUI, MusicGen, and AudioGen.

## 🏗️ Architecture Overview

Bookflix is built on a modern, high-performance stack designed for agentic sovereignty and production-grade stability.

### 1. The Directorial Frontend (Next.js / Expo)
- **Aesthetic**: A "Magical Realism" design system with golden typography and cinematic micro-interactions.
- **State Management**: Real-time production tracking with immersive directorial feedback.

### 2. The Relational Backend (Convex)
- **Functions**: Serverless, type-safe orchestration logic.
- **Database**: Relational storage for Production Decks, World Bibles, and Asset Metadata.
- **File Storage**: Native Convex storage for scripts, storyboards, and final renders.

### 3. The Orchestration Layer (NVIDIA NIM & LLMs)
- **Directorial Agents**: Llama 3.1 (70B/405B) models orchestrated via NVIDIA NIM for high-speed, theory-aware reasoning.
- **Theoretical Synthesis**: Integration of advanced musicology (White, CineNoir) and cinematic semiotics.

### 4. The Synthesis Fleet (Modal & ElevenLabs)
- **Visual Synthesis**: ComfyUI workflows deployed on A100/H100 clusters for theatrical-grade image and video generation.
- **Audio Synthesis**: ElevenLabs Sovereign Voice pipeline integrated with classical harmonic orchestration.
- **Foley & Music**: Dynamic generation via MusicGen/AudioGen, tailored by the Music Theorist's technical DNA.

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- [Convex Account](https://convex.dev)
- NVIDIA NIM API Keys
- ElevenLabs API Key
- Modal Account (for GPU fleet)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shaolin/bookflix.git
   cd bookflix
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Initialize the Backend**:
   ```bash
   npx convex dev
   ```

4. **Launch the Studio**:
   ```bash
   npm run dev
   ```
