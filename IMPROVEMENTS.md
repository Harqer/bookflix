# BookCinema Core Logic Improvements & Production Roadmap

This document identifies current placeholders and outlines the step-by-step path to a production-grade GenAI film studio.

## 1. Current Placeholders & Deficiencies

### A. Orchestration Disconnect
- **Current**: `orchestrateV4` uses `runVisualDirector` which outputs simple text prompts.
- **Problem**: It ignores the rich cinematographic data (Camera Trajectories, Lighting, Blocking) generated by the `AIDirectorAgent`.
- **Production Need**: Pass full `DirectorDecision` objects to MCP servers.

### B. "Static" Video Production
- **Current**: `runVideoProducer` only generates static keyframes (images).
- **Problem**: There is no actual video generation or temporal consistency logic.
- **Production Need**: Integrate Runway Gen-3 Alpha, Luma Dream Machine, or Minimax API for high-fidelity video clips.

### C. Context Window Limits
- **Current**: `runBookAnalyst` only looks at the first 8000 characters.
- **Problem**: Deep narrative structure and late-game characters are missed.
- **Production Need**: Implement a recursive summarization or a multi-pass analysis pipeline.

### D. Mocked DCC & Production Tracking
- **Current**: `callMCP` and `ShotGridClient` are mostly logging-only mocks.
- **Problem**: No actual integration with Blender, Nuke, or ShotGrid exists.
- **Production Need**: Real MCP SDK integration and ShotGrid REST API implementation.

### E. Placeholder RAG & Embeddings
- **Current**: `generateEmbedding` returns deterministic random arrays.
- **Problem**: Continuity Supervisor and World Bible extraction are not based on semantic search.
- **Production Need**: Integrate OpenAI/HuggingFace embeddings and a local ChromaDB instance.

## 2. Production Step-by-Step Roadmap

### Step 1: Unified Directing (The Data Bridge)
- **Action**: Refactor `orchestrateV4` to use `AIDirectorAgent` as the primary decision engine.
- **Result**: ShotGrid and Blender receive precise XYZ camera paths and lighting temperatures instead of vague descriptions.

### Step 2: Temporal Consistency (GenAI + CG)
- **Action**: Implement "CG-Augmented Video Generation."
- **Workflow**: 
  1. Render CG structural passes (depth/normals) from Blender via MCP.
  2. Send CG passes + Visual Prompt to a ControlNet-aware GenAI model (e.g., Stable Video Diffusion or Runway Gen-3).
  3. This ensures the GenAI follows the Director's exact camera moves.

### Step 3: Long-Form Context (The Library Agent)
- **Action**: Replace the 8000-char analysis with a "Library Agent" that:
  1. Reads the entire book in chunks.
  2. Updates a persistent Vector DB (RAG).
  3. Generates a global "Story Map" before chapter splitting.

### Step 4: Real-World Tooling (MCP & ShotGrid)
- **Action**: Finalize the `ShotGridClient` using the `ShotGrid REST API`.
- **Action**: Implement the `MCP Client` to trigger local/remote Blender instances using the scripts generated by `AIDirectorAgent`.

### Step 5: Final Assembly & Audio
- **Action**: Implement an "Editor Agent" that:
  1. Stitches the video clips together (via FFmpeg MCP).
  2. Generates spatial audio and dialogue (via ElevenLabs/Meta Audio).
  3. Adds cinematic scores (via Suno/Udio API).
